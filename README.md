# Clipboard Manager

Save text snippets locally and re-copy them later.

## Features
- Add snippets manually
- Pin favorites
- Search history
- Persist via localStorage

## Limitations
- Cannot read the system clipboard continuously (browser security)
- Data never leaves this origin

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
